# Hotel Booking System

A Hotel Booking System built using React.js, JavaScript, HTML, CSS, and Bootstrap. The application allows users to browse hotels, view hotel details, explore facilities and pricing, and book a hotel of their choice.

Users need to log in before proceeding with a hotel booking. The project is currently in its initial development stage, with more features planned for future updates.

## Features

- Browse available hotels.
- View hotel details, images, facilities, and pricing.
- Login required before booking a hotel.
- Navigate between pages using React Router.
- Responsive user interface.
- Reusable React components.
- Interactive functionality using React Hooks.

## Technologies Used

- HTML5
- CSS3
- JavaScript (ES6+)
- React.js
- Bootstrap 5
- React Router DOM
- Bootstrap Icons
- React Icons
- Lucide React

## Getting Started

Follow these steps to run the project on your local machine.

**1. Clone the repository**

```bash
git clone https://github.com/supriyasarode1925/Hotel-Booking-System.git
```

**2. Open the project folder**

```bash
cd Hotel-Booking-System
```

**3. Install dependencies**

```bash
npm install
```

**4. Run the development server**

```bash
npm run dev
```

Open the localhost URL displayed in your terminal to view the application.
